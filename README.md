# pp-watch
PiouPiou ([OpenWindMap](https://www.openwindmap.org/) sensor) Watcher project.

* pp-watch.py - command line client
* pp-watch-kde.py - desktop tray application (originally, for KDE)

Before using, put the desired pioupiou number in the source code.

Requires Python 3; the desktop application requires PyQt6. Tested on Fedora 45.

Originally written for Python 2.7 / PyQt 4.11 (Fedora 24).

Check [Wiki](https://github.com/denis-stepanov/pp-watch/wiki) for more information.
